# 即物穷理 Praxic v0.2.0

本版本重点修复 Windows 安装后“Python 后端超时未就绪”的启动故障，并整理历史遗留文件与发布流程。

## 修复

- 冻结后端直接启动服务，修复将 exe 当作 Python 解释器再次执行导致的退出。
- 配置与数据写入用户可写目录，避免安装目录权限导致启动失败。
- 桌面端收集标准输出和错误输出；后端提前退出时立即显示错误，健康检查不再把 HTTP 500 当作启动成功。
- 补齐文件上传依赖和页面静态资源，不再随桌面启动额外打开浏览器。
- 归档旧计划、临时脚本与内部运行轨迹，纠正文档和版本漂移。
- 发布前执行测试及冻结后端启动检查，附 SHA256SUMS.txt 供核对下载完整性。

## 安装与升级

- Windows 用户下载名称包含 `win` 的 `.exe` 安装包。
- Windows 安装包尚未进行数字签名，系统可能显示未知发布者提示。请从本 release 下载并核对哈希；不要关闭系统安全保护来绕过异常。
- macOS 构建未签名、未公证；Linux 提供 AppImage/deb。文件名标明平台及架构，请选择匹配的版本。
- 桌面版运行数据位于 Electron 用户数据目录下的 `backend` 子目录。旧版本安装目录中的配置和数据不会自动迁移或删除，升级前请备份；可使用 `PRAXIC_RUNTIME_DIR` 指定运行目录。

## 验证边界

发布流程验证自动化测试和冻结后端的健康接口、首页、静态资源及中文空格路径；这些检查不等同于所有用户环境下完整安装、卸载和模型调用验收。页面的部分资源仍需联网加载。
